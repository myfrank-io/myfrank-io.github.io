# Terrain Visible

Site éditorial créé et exploité par MyFrank. Il publie des méthodes originales sur la satisfaction client et la visibilité locale, sans se présenter comme un tiers indépendant. URL initiale : `https://ranksas.github.io/` ; un domaine propre pourra être ajouté plus tard après vérification de disponibilité et achat.

## Développement

```sh
npm ci
npm run build
npm test
```

Le calculateur n'envoie aucune donnée. Les liens vers MyFrank sont contextuels et portent des paramètres UTM ; la mesure réelle des visites et leads doit être vérifiée côté analytics, pas inférée du nombre d'articles.

## Publication et contributions

La branche `main` est déployée par GitHub Pages après `npm test`. Les contributions arrivent par e-mail et ne sont publiées qu'après revue des faits, des droits, de l'originalité et des données personnelles. Ne pas accepter de liens payants, de témoignages inventés ou de cas non vérifiables. Préférer un article utile à un quota quotidien de pages faibles.

Plan opérationnel : `docs/editorial-operations.md`.
