# Contribuer au Terrain Visible

Une contribution utile décrit une situation réelle, ce qui a été vérifié, l’action tentée et ce qui reste incertain. Les retours contradictoires et les corrections sont bienvenus.

## Proposer un cas ou une correction

Écrivez à [contact@myfrank.io](mailto:contact@myfrank.io?subject=Terrain%20Visible%20-%20contribution) avec pour objet « Terrain Visible — contribution ». Cette adresse est celle de notre éditeur MyFrank. Aucun compte GitHub n’est nécessaire et aucun texte reçu n’est publié automatiquement.

Indiquez le secteur, le problème étudié, la méthode de vérification, les limites et les sources autorisées à être citées. Ne joignez ni identité de client, ni conversation privée, ni capture contenant des données personnelles.

## Notre revue

Nous contrôlons l’originalité, les faits vérifiables, les droits sur les médias et la pertinence pour les lecteurs. Nous pouvons demander une précision ou refuser une proposition. Un lien commercial n’achète pas une publication. L’auteur choisi pour la publication est crédité avec son accord ; tout lien vers une activité liée est signalé. Le site reste édité par MyFrank.

Les contributions restent des propositions tant qu’elles ne sont pas publiées ici. Pour améliorer une page existante, citez son URL et la phrase à corriger.
